# Expense Tracker

A simple Expense Tracker web application built with plain HTML, CSS, and JavaScript.
Users can add income and expense transactions, edit and delete them, view totals,
filter by type or category, and the data is saved in the browser using Local Storage.

## Tech Stack

- HTML
- CSS
- JavaScript (ES Modules)

## How to Run

No build step or installation is required.

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

That's it, the app runs entirely in the browser.
